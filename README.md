# Dirac Notation Quantum Simulator

## Overview
This project is an interactive web-based simulator that demonstrates the basics of quantum mechanics using Dirac notation.

It allows users to:
- Learn theoretical concepts of Dirac notation
- Apply quantum operators
- Measure quantum states
- Visualize measurement probabilities

The simulator helps in understanding quantum states and quantum gates in an intuitive way.


## Features
- Learn section with:
  - Ket and Bra notation
  - Basis states
  - Inner product
  - Normalization
  - Outer product
  - Tensor product
  - Quantum gates
  - Measurement theory

- Simulator section with:
  - State input \( |\psi\rangle = a|0\rangle + b|1\rangle \)
  - Quantum operators:
    - Identity
    - Pauli-X
    - Pauli-Z
    - Hadamard
  - Operator matrix display
  - Probability visualization bars
  - Automatic normalization handling
    

## Technologies Used
- HTML
- CSS
- JavaScript
- MathJax (for rendering equations)
- GitHub Pages (for deployment)
  

## How to Use
1. Enter values for coefficients **a** and **b**
2. Select a quantum operator
3. Click **Measure State**
4. View output state and probability bars
